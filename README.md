# Dice-Roll-App
# 🎲 Dice Game

A simple and interactive **Dice Rolling Game** built using **HTML, CSS, and JavaScript**. This project simulates rolling a dice with animation and dynamically updates the result on the screen.

---

## 🚀 Features

* 🎲 Random dice roll (1–6)
* 🎞️ Dice rolling animation using CSS
* 🔄 Dynamic image update based on result
* 🧠 Real-time result display in heading
* 🎨 Clean and minimal UI design

---

## 🧠 How It Works

* When the **"Roll Dice"** button is clicked:

  1. A random number between **1 and 6** is generated using JavaScript.
  2. A **rolling animation** is applied to the dice image.
  3. After a short delay, the animation stops.
  4. The dice image updates according to the generated number.
  5. The heading text displays the result (e.g., *"You rolled a 4!"*).

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and animation (keyframes)
* **JavaScript (Vanilla JS)** – Logic and interactivity
